## 🚀 QUICK START

```bash
# 1. Clone o repositório
git clone https://github.com/Symbios-Matverse/matverse-core.git
cd matverse-core

# 2. Instale o engine
cd symbios-engine
pip install -e .[dev,dashboard,quantum,blockchain]

# 3. Execute testes
python -m pytest tests/ -v

# 4. Inicie o dashboard
python deployment/huggingface/app.py
```
